# Лабораторна робота №2: Побудова фракталів

Цей репозиторій містить реалізації завдань другої лабораторної роботи, присвяченої **побудові фракталів за допомогою рекурсивних алгоритмів**. Основний фокус зосереджений на рекурсії, геометричних обчисленнях, роботі з координатами та візуалізації самоподібних структур.

Усі завдання реалізовані мовою **JavaScript** із використанням **HTML5 Canvas** для відображення графіки у браузері. Кожне завдання розміщене в окремій папці.

## 📋 Опис реалізованих завдань

1. **Трикутник Серпінського (Sierpiński Triangle):** Рекурсивний поділ трикутника на менші частини. Обчислення середин його сторін, побудова внутрішнього трикутника та повторення алгоритму для трьох кутових трикутників.
2. **Килим Серпінського (Sierpiński Carpet):** Поділ квадрата на сітку 3×3, виділення центрального квадрата та рекурсивне повторення побудови для восьми навколишніх частин.
3. **Фрактальне дерево (Дерево Піфагора — гілки):** Рекурсивна побудова дерева з відрізків. На кожному кроці довжина гілки зменшується, а з її кінця утворюються нові гілки під заданими кутами.
4. **Множина Кантора (Cantor Set):** Рекурсивне ділення відрізка на три рівні частини з подальшою побудовою лише двох крайніх третин. Відображення послідовних рівнів побудови.
5. **Класичне дерево Піфагора (Pythagoras Tree):** Побудова фрактала з квадратів. Для кожного квадрата обчислюються координати та кути повороту двох менших квадратів, після чого алгоритм рекурсивно повторюється.
6. **Крива та сніжинка Коха (Koch Curve & Snowflake):** Рекурсивна заміна одного відрізка чотирма меншими з утворенням трикутного виступу. Сніжинка будується застосуванням тієї самої процедури до трьох сторін початкового трикутника.

## 🧠 Використані алгоритми та концепції (Словник термінів)

- **Recursion (Рекурсія):** Метод, за якого функція викликає сама себе для побудови менших частин фрактала.
- **Base case (Базовий випадок / Умова виходу):** Умова завершення рекурсивних викликів, наприклад досягнення нульової глибини або мінімальної довжини відрізка.
- **Recursion depth (Глибина рекурсії):** Кількість рівнів повторення алгоритму, яка визначає деталізацію фрактала.
- **Self-similarity (Самоподібність):** Властивість фрактала, за якої його окремі частини повторюють форму всієї фігури в меншому масштабі.
- **Coordinate geometry (Координатна геометрія):** Обчислення положення вершин, середин відрізків і нових елементів фігур за координатами точок.
- **Geometric transformations (Геометричні перетворення):** Масштабування, зміщення та поворот фігур для створення наступних рівнів фрактала.
- **Trigonometry (Тригонометрія):** Використання `Math.sin()`, `Math.cos()` та кутів у радіанах для визначення координат похилих відрізків і повернутих фігур.
- **Call stack (Стек викликів):** Механізм, який зберігає стан кожного рекурсивного виклику та дозволяє повернутися до попереднього рівня після його завершення.
- **HTML5 Canvas API:** Засоби малювання двовимірної графіки у браузері за допомогою JavaScript, зокрема `getContext('2d')`, `moveTo()`, `lineTo()` та `stroke()`.

## 🚀 Запуск коду

Для запуску достатньо сучасного веббраузера.

1. Перейдіть до папки потрібного завдання.
2. Відкрийте HTML-файл цього завдання у браузері.
3. Браузер автоматично підключить відповідний файл `script.js` і відобразить фрактал на елементі `<canvas>`.

**Примітка:** На відміну від першої лабораторної роботи, ці програми використовують браузерний Canvas API, тому запускати їх командою `node` не потрібно.
